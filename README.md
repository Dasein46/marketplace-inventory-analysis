# Продажи и запасы маркетплейса

Учебный кейс по управлению ассортиментом при отсутствии поставок в течение 30 дней. Анализ объединяет запас в днях и маржу, чтобы выделить товары для первоочередного контроля.

**Автор — Эдуард Леонов.** Инструменты проекта — Google Sheets и Yandex DataLens. Исходные данные предоставлены в учебном тестовом задании и обозначены как вымышленные. Период продаж — 9–16 ноября 2022 года, восемь календарных дней.

## Задача и результат

Поставок не будет ближайшие 30 дней. Требуется оценить, какие товары закончатся раньше этого срока, и определить приоритеты контроля с учётом их вклада в маржу.

| Показатель | Значение |
| --- | ---: |
| Уникальные артикулы | 456 |
| Продано за восемь дней, шт. | 41 927 |
| Остаток с однократным учётом каждого артикула, шт. | 20 404 |
| Артикулы с запасом менее 30 дней | 294 |
| Артикулы с запасом до семи дней включительно | 148 |
| Выручка для расчётов, ₽ | 39 401 362,09 |
| Маржа после комиссии и себестоимости, ₽ | 15 227 589,57 |
| Маржа критических артикулов, ₽ | 12 090 589,75 |
| Доля маржи критических артикулов | 79,4% |

148 критических артикулов обеспечили 79,4% общей маржи за наблюдаемый период. Это показывает концентрацию маржи в товарах, запаса которых при прежнем темпе продаж хватит максимум на семь дней. Доля описывает прошлые продажи, а оценка срока исчерпания основана на постоянном темпе спроса.

Наибольшая маржа критических артикулов приходится на YORK — 5,96 млн ₽, «Атлас принт» — 2,77 млн ₽ и «Экомебель» — 1,95 млн ₽. Например, артикул 64354767 принёс около 1,22 млн ₽ маржи. Продажи составили 3 599 шт., остаток — 160 шт., расчётный запас — 0,36 дня.

Рекомендации по результатам анализа

- Ежедневно контролировать критические позиции с высокой положительной маржой, начиная с фактического наличия товара и корректности остатков.
- Проверить возможность перераспределения имеющегося запаса между складами и предложить покупателям доступные аналоги.
- Для дефицитных товаров проверить участие в акциях и рекламе. Изменения цены тестировать с учётом реакции спроса и маржи.
- Для товаров с отрицательной маржой проверить цену, комиссию и себестоимость перед дополнительным продвижением.

## Подготовка данных

В Google Sheets рассчитаны показатели по товарам, брендам и товарным группам, созданы сводные таблицы и подготовлены рекомендации. Затем создана витрина для DataLens из 456 строк — одна строка на артикул. Данные продаж, комиссии и себестоимости суммированы по артикулу.

В исходных 1 009 строках повторялись артикулы. У всех 201 повторяющегося артикула остаток совпадал во всех строках. Для кейса принят единый снимок остатка по артикулу, поэтому он учитывается один раз. Суммирование исходных строк дало бы 49 594 шт. вместо 20 404 шт.

В трёх строках при нулевом количестве продаж была указана положительная сумма — всего 13 265 ₽. Эти суммы исключены из выручки для расчётов. Строки сохранены при подготовке данных, остатки учтены. Наличие продаж проверяется после объединения строк каждого артикула.

Товарные группы выделены из текстовых описаний по ключевым словам. Для 95 артикулов группа осталась «не определено». Варианты регистра названия бренда YORK приведены к одному написанию.

Файл `data/marketplace_inventory.csv` содержит подготовленную витрину для воспроизведения дашборда. Упомянутые проверки исходных строк выполнены до создания этой витрины.

## Поля витрины

| Поле | Содержание |
| --- | --- |
| Артикул | Идентификатор товара, тип «Строка» |
| Бренд | Нормализованное название бренда |
| Товарная группа | Группа, выделенная из описания товара |
| Остаток, шт | Остаток, учтённый один раз на артикул |
| Продано, шт | Количество проданных единиц за восемь дней |
| Выручка до комиссии, руб | Выручка после исключения аномальных сумм, по принятому допущению до комиссии |
| Комиссия, руб | Сумма выручки каждой исходной строки, умноженной на её ставку комиссии |
| Себестоимость продаж, руб | Сумма произведений количества продаж на себестоимость единицы |

## Формулы DataLens

Запас в днях рассчитывается для каждого артикула. При нулевых продажах `FDIV_SAFE` возвращает `NULL`.

```text
FDIV_SAFE([Остаток, шт] * 8, [Продано, шт])
```

Маржа в рублях по артикулу

```text
[Выручка до комиссии, руб] - [Комиссия, руб] - [Себестоимость продаж, руб]
```

Количество артикулов

```text
COUNTD([Артикул])
```

Артикулы с запасом менее 30 дней

```text
COUNTD_IF([Артикул], [Продано, шт] > 0 AND [Запас в днях] < 30)
```

Артикулы с запасом до семи дней включительно

```text
COUNTD_IF([Артикул], [Продано, шт] > 0 AND [Запас в днях] <= 7)
```

Маржа критических артикулов в рублях

```text
ZN(SUM_IF([Маржа, ₽], [Продано, шт] > 0 AND [Запас в днях] <= 7))
```

Доля маржи критических артикулов. В числителе используется поле «Маржа критических артикулов, ₽». Для отображения выбирается процентный формат.

```text
FDIV_SAFE([Маржа критических артикулов, ₽], SUM([Маржа, ₽]))
```

## Как воспроизвести

1. В DataLens создать воркбук и подключение типа «Файлы», загрузить `data/marketplace_inventory.csv`. Кодировка UTF-8, разделитель — запятая, первая строка содержит заголовки. Дробные значения записаны с точкой.
2. Создать датасет. Для артикула, бренда и товарной группы выбрать строковый тип, для количества и остатка — целочисленный, для денежных полей — дробный. Добавить вычисляемые поля по формулам выше. Назвать поле маржи «Маржа, ₽», поле срока — «Запас в днях».
3. Создать четыре индикатора с количеством артикулов, двумя порогами запаса и долей маржи критических артикулов.
4. Создать таблицу с артикулом, брендом, товарной группой, продажами, остатком, запасом в днях и маржой. Применить условия «Продано, шт > 0» и «Запас в днях <= 7», сортировать по запасу в днях по возрастанию.
5. Создать линейчатую диаграмму. По Y — бренд, по X — маржа критических артикулов. Сортировать по марже по убыванию.
6. Добавить виджеты на дашборд и селектор по бренду на том же датасете. Без фильтра контрольные значения — 456 / 294 / 148 / 79,4%. Для «Атлас принт» — 12 / 10 / 9 / 99,8%.

## Допущения и ограничения

- Формулировка исходного задания о комиссии неоднозначна. Принято, что «Продажа (руб)» содержит сумму до её удержания. При трактовке исходной суммы как выплаты продавцу потребуется другой расчёт выручки и маржи.
- Запас в днях оценивает покрытие текущего остатка при среднем спросе за восемь дней. Изменения спроса, сезонность и реакция покупателей на цены не моделируются.
- Учитываются только комиссия и себестоимость проданных товаров. Данные о рекламе, логистике, хранении, налогах и других расходах отсутствуют.
- Доля маржи использует итоговую маржу с учётом отрицательных значений. При нулевой общей марже результат не определён. При отрицательных суммах интерпретация доли требует отдельного разбора.
- Единый остаток по артикулу принят на основе повторяющихся значений в учебных данных. Для реального отчёта необходимо подтвердить уровень детализации остатка у владельца источника.
- При отображении всех брендов небольшие денежные значения на диаграмме округляются до 0,00 млн ₽. Точные значения отдельных артикулов доступны в таблице.
